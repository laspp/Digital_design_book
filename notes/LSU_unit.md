# LSU stage


- The design of memory stage closely resembles to the previous ones 
- The role of this is stage is to provide access to memory during the load and store operations. Therefore it have following properties:
    - Communicates with memory through OBI interface
    - Unlike the IFU stage, the LSU stage features writing to memory (for store operations) alongside to reading (load operations)
    - The stage does not need constantly to access the memory. If the current instructions is not load or store, we will just pass through the stage to the writeback stage
    - it features also writeback to the exe stage
